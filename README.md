# COMP 370 HW4: Unix commands & MLP

Exploration of My Little Pony dialog using UNIX command line tools and csvtool.

## Data
The dataset is not committed. Download `clean_dialog.csv` from
https://www.kaggle.com/liury123/my-little-pony-transcript
and place it at `data/clean_dialog.csv`.

## Files
- `explore.md`: answers to Tasks 3 and 4, with the commands used
- `Line_percentages.csv`: share of all lines spoken by each main pony
- `scripts/line_percentages.sh`: generates `Line_percentages.csv`

## Run
    ./scripts/line_percentages.sh# comp370-Hw4
